# سایت معرفی پول‌بین

یک صفحه‌ی ساکن، بدون فریم‌ورک و بدون سرور. کل پوشه همان چیزی است که روی هاست
می‌رود؛ چیزی برای اجرا کردن در سمت سرور ندارد.

## چرا اینجاست و نه در مخزن جدا

دموی «خودت امتحانش کن» مستقیم از `src/services/smsParser.ts` خودِ اپ استفاده
می‌کند، نه یک کپی. اگر پارسر اپ بهتر شود، سایت هم همان لحظه بهتر می‌شود و
هیچ‌وقت دو رفتار متفاوت نشان داده نمی‌شود. این فقط به این دلیل ممکن است که آن
فایل (و `utils/`، `data/`) هیچ وابستگی به ری‌اکت‌نیتیو ندارند — همان دلیلی که
تست‌های Jest هم بدون شبیه‌ساز اجرا می‌شوند.

## ساخت

```bash
npm run site        # site/demo.ts → site/assets/demo.js
npm run site:serve  # http://127.0.0.1:8777
```

`site/assets/demo.js` ساخته می‌شود ولی در گیت نگه داشته شده تا انتشار، به
داشتن Node روی سرور یا CI نیاز نداشته باشد. **بعد از هر تغییر در پارسر،
`npm run site` را دوباره بزن**، وگرنه سایت با نسخه‌ی قدیمی می‌ماند.

## نکته‌ها

- `site/tsconfig.json` جداست چون این کد DOM دارد و اپ ندارد؛ tsconfig ریشه
  پوشه‌ی `site` را کنار می‌گذارد تا تایپ‌های مرورگر به کد اپ نشت نکند.
- اسکرین‌شات‌ها از `store/screenshots/` با عرض ۴۲۰ و فرمت JPEG ساخته شده‌اند
  (هر کدام حدود ۳۰ کیلوبایت به‌جای ۱۸۰).
- لینک «دریافت از بازار» در `index.html` صفحه‌ی اپ در کافه‌بازار است:
  <https://cafebazaar.ir/app/com.polbin>
